# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, by reference. The full
text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and
applies to all project spaces: issues, pull requests and discussions.

To report a concern privately, use the repository's
[security advisory form](https://github.com/Riedel-David/Beyond-Borders/security/advisories/new);
it is the only private channel the project has, so say that the report is about conduct,
not a vulnerability. Reports are handled privately by the maintainer.
