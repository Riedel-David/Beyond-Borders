# Contributing

Issues and pull requests are welcome. Before opening a PR:

- Read the README for the build commands.
- `./gradlew :app:testDebugUnitTest` must be green; CI runs it on every PR.
- The app is offline-first by design: no feature may need a network connection, and
  the `INTERNET` permission stays removed.
- Reference data under `app/src/main/assets/` is generated by `tools/`; change the
  generator, not the output, and record sources in `ASSET_SOURCES.md`.
- Visa data is a snapshot from a third party, not legal advice. Fixes to a
  specific answer belong in `tools/visa/rules.py` with a comment saying why.
